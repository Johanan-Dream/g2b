# 공개 범위와 규정 검토

확인일: 2026-10-21. 공개 페이지에 근거한 저장소 편집 판단이며, 주최 측의 별도 공개 허가를 받았다는 의미는 아닙니다.

## 확인한 근거

| 공식 문서 | 확인한 내용 | 이번 저장소에 적용한 판단 |
|---|---|---|
| [동의사항 B.7](https://dacon.io/competitions/official/236754/overview/agreement) | 대회 데이터에는 제공 실행 코드도 포함되며 비참가자에게 재배포하는 것을 제한 | 배포 데이터·공식 베이스라인·관련 파생 자료 제외 |
| [동의사항 B.8](https://dacon.io/competitions/official/236754/overview/agreement) | 공개 코드 공유는 데이콘 플랫폼을 통해 진행하도록 명시 | GitHub에 대회 실행 코드와 테스트를 게시하지 않음 |
| [동의사항 A](https://dacon.io/competitions/official/236754/overview/agreement) | 상장 또는 상금이 지급되는 수상작의 권리 귀속 및 사전 서면 동의 조건 | 수상 여부를 추정하지 않고 제출 산출물 제외 |
| [대회 규칙 2.2](https://dacon.io/competitions/official/236754/overview/rules) | 참가자 생성 라벨·가공 자료의 공유는 대회 코드 공유 게시판을 통한 전체 공개만 허용 | 라벨·예측·사례집·검색 자산 제외 |

대회 종료만으로 위 제한이 해제된다고 가정하지 않았습니다. 외부 GitHub에 실행 코드를 게시할 수 있다는 명시적 예외는 확인하지 못했습니다.

## 포함한 자료

새로 작성한 프로젝트 소개와 일반적인 접근 설명, 개발 회고, 개별 샘플을 복원할 수 없는 집계 성과 기록과 공식 공개 리더보드의 화면 캡처를 포함합니다. 원문 인용, 공고 식별자, 개별 레이블, 프롬프트 전문, 구현 세부 규칙은 담지 않습니다.

규정에서 해당 문서의 공개를 명시적으로 승인한 것으로 해석한 것이 아니라, 제한 대상 자료를 배제한 보수적인 공개 범위입니다.

## 제외한 자료

- `inputs/`: 제공 원본, 라벨, 법령 패키지, 공식 베이스라인.
- `submission/`, `tools/`, `tests/`, `experiments/`: 실행 코드, 실험 구현 및 테스트 사례.
- `submission/examples.json`: 제공 자료에서 만든 사례 자산.
- `output/`, `reports/`, `dist/`: 모델 응답, 개별 예측, 상세 분석, 제출 ZIP.
- `models/`, `.cache/`, `.venv/`: 모델 가중치, 캐시, 로컬 환경.
- `CONTEST_STATE.md`: 식별자와 내부 실험 기록이 포함된 작업 문서.
- 인증정보, 환경변수 파일, 개인 경로 및 임시 파일.

`.gitignore`는 검토된 문서·설정 파일 다섯 개와 리더보드 캡처 두 개·출처 JSON 한 개만 허용합니다. 기존 로컬 자료는 보존하며 Git 추적 대상에서 제외합니다. 강제 추가(`git add -f`)는 이 보호를 우회하므로 사용하지 않습니다.

## 코드 공개를 확대하려면

주최 측의 GitHub 게시 허용 범위, 데이콘 플랫폼 공개 조건 및 수상 산출물 권리를 먼저 확인해야 합니다. 승인되지 않은 공식 베이스라인이나 자료를 함께 재배포하지 않아야 합니다. 저장소 전체에 임의의 오픈소스 라이선스를 부여하지 않았습니다.
